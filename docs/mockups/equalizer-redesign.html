What Changes

Equalizer Bands

  • 5-band curve → 10-band vertical sliders
  • Circular thumbs with glow effect
  • Gain value above, frequency below
  • Per-band vertical drag gesture

FX Cards (Bass/Loudness/Virtualizer)

  • Toggle rows → Circular gauge cards
  • 3-column grid layout
  • Percentage/dB value in center
  • Mini toggle at bottom of each card

Color & Spacing

  • Pink-violet → Cyan/teal accents
  • Consistent 16-20dp rhythm
  • Subtle glass backgrounds per section
  • Darker, cleaner overall feel

NowPlaying Queue Polish

  • Better artwork sizing (40→44dp)
  • Refined text hierarchy
  • Smoother playing indicator
  • Better drag handle styling
