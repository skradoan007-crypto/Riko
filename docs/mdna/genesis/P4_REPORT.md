## What is reachable

**Now Playing -> Visualizer -> Open MDNA Genesis**. This entry and DnaLabScreen
are in `main`, available to release builds without a debug flag. Back returns to
the existing Visualizer Lab; the overlay back-handler order now allows this
nested screen to consume Back first. Playback uses the existing PlayerViewModel
play/pause action. No second player, new permission, cloud service or static
reference-image background was introduced.

Opening a song loads its cached Room DNA profile, or analyzes it off the UI thread
through P2's shared/cancellable decoder. Leaving/stopping the screen cancels the
analysis. An immediate P0 live orb remains available while analysis runs or fails.
The complete result is mapped using P1 and inserted once through P3, then published
as immutable render parameters. Track changes clear the previous genome before
loading the next. URI/size/modified-time hash is only a local cache key; base DNA
still derives from decoded audio and canonical musical features.

## Rendering architecture

- `DnaOrganism` owns the existing lifecycle-aware GLSurfaceView host. Choreographer
  requests frames; the GL thread samples interpolated live spectrum and updates
  uniforms, independently of ordinary Compose recomposition. UI diagnostics poll
  at 2 Hz. Actual sample rate is forwarded to the band grouping.
- Orb: layered, continuously deformed latitude spirals and fine luminous points.
  Terrain: connected serpentine contour ribbons, waves and spectral-energy peaks.
  Nebula: layered flowing particle formations with localized transient response.
  Seed, chroma distribution, symmetry, brightness, deformation, density, layers,
  flow, sharpness and microdetail produce variations within these families.
- Shared ESSL 3.00 geometry is generated by gl_VertexID. No mesh regeneration or
  vertex upload per frame. Uniform arrays and matrix buffers are reused; programs
  and locations are cached. Failed programs are not recompiled every frame.
- Bass expands geometry, mids deform surfaces, treble changes fine detail and
  brightness, and live beat envelope drives genome-scaled transient response.
  Cyan/blue/violet colour transitions remain spatially coherent.
- Quality controls retain automatic downgrade protection. Low/Mid/High scene
  framebuffer scales are 0.6/0.8/1.0; targets are recreated only on size/tier
  changes. Point budgets are row-aligned, capped at 32,736 per layer and 163,680
  total. These are limits, **not measured device performance**. Optional bloom
  failure uses direct GLES rendering. GLES <3.0 reports unsupported while playback
  continues. API 26–32 uses the same GLES 3 path; no RuntimeShader dependency.
- Renderer lifecycle, GPU cleanup/context-loss handling and manual route-specific
  AV offset are retained. Freeze-motion control and the system animator-disabled
  preference reduce motion; playback pause stops the motion clock. P0's separate
  API-33 AGSL debug atmosphere remains intact, not relabeled as GLES shader code.
- Standalone debug template cycling skips genome-only shaders, preventing blank
  uninitialized scenes. Existing basic drag/pinch support is retained; P5's full
  interaction, inertia, pulse/haptics/accessibility work is not claimed.
