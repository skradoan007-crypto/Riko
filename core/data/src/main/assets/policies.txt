PRIVACY AND LOCAL STORAGE
No account, advertising, analytics or custom server is included. Favorites, recent copies, appearance preferences, notice acknowledgement and imported custom files are stored locally. This app copies only the item you select; it does not monitor or read your global clipboard. Android and apps you paste into manage subsequent clipboard access.

Optional copy reminders display the last item copied in this app when you leave within ten seconds. Android 13+ requires notification permission. You can disable the setting. Other people looking at your device may see a notification; lock-screen content is marked private. Android controls popup appearance, timing and notification cooldown.

The system file picker grants access only to a file you select. Imported models are copied to app-private storage. Exported files go to the location you select. Bundled models are exposed read-only through Android's document picker. The app does not upload custom files, favorites or history. Removing a custom file removes its private copy. Clearing app data or uninstalling removes private data; exported files and clipboard copies remain separately managed. Cloud backup is disabled for this app.

EXTERNAL SERVICES
Google Play handles update checks and distribution under its own terms. Opening an external store/source/plugin URL uses another app/service, which may receive your IP address and connection information. Downloading a plugin in the game requires that game's network connection. These services have their own policies.

USE AND COMPATIBILITY
Use only files you own or have permission to use and follow the game's terms. Source descriptions and header checks do not guarantee compatibility. This app does not execute or render imported models. The game decides whether it can load them. Direct load is attempted only if the installed game advertises a compatible Android file-opening action; otherwise use the game's own RGS picker.
